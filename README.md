# RPG Matchmaker

Um projeto em flutter de um aplicativo voltado para unir pessoas do ramo do RPG de Mesa

## 📥 Download

Você pode baixar a versão mais recente clicando [![neste link para a pagina do github](https://shields.io)]([https://github.com](https://github.com/GiovanniBrandao/rpg-matchmaker/releases/tag/v1.0.0-beta)), e baixando o arquivo APK.

### Como instalar
1. Acesse a aba **Releases** no link acima.
2. Em **Assets**, baixe o arquivo correspondente ao seu sistema (ex.: `NomeDoApp-Setup.exe` ou `app-release.apk`).
3. Execute o instalador e siga as instruções na tela.

## OBS: Ele funciona inicialmente apenas para Android
